## Решения по UX

1. **Одно меню вместо двух.** У гражданина меню разделов ЭПЗ внутри страницы скрыто: подразделы ЭПЗ —
   прямо в меню кабинета (`CitizenNav`), группа «Электронный паспорт здоровья» раскрыта на страницах ЭПЗ.
   «Управление доступами к ЭПЗ» — отдельным пунктом. Карточка «кто вошёл» компактнее — меню помещается
   на 1366×768. Адрес раздела прежний (`Просмотр ЭПЗ.dc.html#allergy`).
2. **Главная ЭПЗ гражданина** — без повторной карточки ФИО/ИИН: строка «Электронный паспорт здоровья ·
   синхронизировано с ЕГИС ЗРК · время» + «Обновить данные»; показатели, аллергия, прикрепление;
   «Разделы ЭПЗ» плитками (иконка, название, число записей) — быстрый доступ.
3. **Каркас раздела**: шапка (иконка, H1, бейдж «N записей», «Экспорт отчёта») → панель фильтров →
   таблица в плашке (`border`, шапка таблицы, строки 52–56, «глаз» в последнем столбце) → подвал
   «Показано 1–N из M» + пагинация. Без подзаголовков-пояснений и KPI-плиток.
4. **Единое окно ЭПЗ** (`epz-modal`): по центру, 720/880 px, шапка (иконка + заголовок + подзаголовок + ×),
   статус-полоса (без повтора текста из блоков ниже), сетка «поле — значение», аккордеоны с бейджем
   количества, подвал (ЭЦП слева; «Распечатать», «Скачать PDF», «Закрыть»), прокрутка внутри, Esc закрывает.
5. **Измерения**: сверху — детали выбранного измерения во всю ширину, ниже — история таблицей (с АД),
   выбор строкой или «глазом».
6. **Диспансерный учёт**: диагнозы на учёте — колонкой слева, справа вкладки в плашке и содержимое;
   история наблюдения — таблица с «глазом» → окно приёма с аккордеонами.
7. Колокольчик уведомлений в шапке (как в Stitch 3) **не делаем** без подтверждения: раздел
   «Уведомления» утверждён 24.11 отдельной страницей. → вопрос аналитику.
