## Решения по UX
- Отдельная страница кабинета (`Уведомления гражданина.dc.html`) вместо раздела `#notif` в «Личном
  кабинете»: старая ссылка `Личный кабинет.dc.html#notif` перенаправляет на неё.
- Данные — живые: уведомления строятся из заявок гражданина (`AttachData`), номер ведёт в настоящую
  карточку. Смена статуса в карточке (панель «Прототип») или новая заявка из мастера сразу дают новое
  непрочитанное уведомление и увеличивают счётчик в меню.
- Без дублей референса: «Открыть заявку →» под каждым уведомлением не нужна — номер и вся строка уже
  ведут в карточку; «Мои заявки» — ссылкой внутри текста, как в постановке.
- Открытие уведомления отмечает его прочитанным. «Отметить все прочитанными» (как у бизнеса) — с отменой
  в тосте вместо окна подтверждения.
- Поиск ищет в текущей вкладке, счётчики вкладок при поиске показывают найденное — видно, где ещё есть
  совпадения. Номер ищется по части («139» находит 0000139), знак «№» игнорируется.
- Кавычки шаблона: в постановке внутренние кавычки „…“, потому что весь шаблон взят в «…». В интерфейсе
  текст стоит сам по себе, поэтому кавычки — «…» (как на мокапе аналитика).
