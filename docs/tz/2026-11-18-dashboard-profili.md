# Дашборд администратора — статистика профилей (18.11.2026)

Страница: `project/Дашборд.dc.html` (кабинет бизнеса → Администрирование → Дашборд, вкладка «Пользователи»).

## Источники
- Word «Доработка дизайна дашборда — статистика профилей пользователей» (16 абзацев, без рисунков) — **истина**.
- Референсы аналитика: `dashboard-mockup.html` (4 карточки + таблица «Профили по типам» с «Итого»)
  и скриншот (карточка «Всего пользователей» + «Все профили» + 4 карточки по типам). Видение, не макет.

## Выжимка
Один пользователь (`users`) может иметь несколько профилей (`users_profile`). Чтобы не путать
пользователей и профили, статистика на дашборде — по профилям.

## Чек-лист
| № | Пункт ТЗ | Где | Статус |
|---|---|---|---|
| 1 | Статистика по профилям, а не по уникальным пользователям | карточка «Профили», «Профили по типам» (считаются профили) | ✅ |
| 2 | Общее количество профилей | «Профили» → «Всего» | ✅ |
| 3 | Отдельно — активные профили | «Профили» → «Активные» + столбец в «Профилях по типам» | ✅ |
| 4 | Отдельно — деактивированные профили | «Профили» → «Деактивированные» + столбец | ✅ |
| 5 | Удалённые профили не учитывать и не показывать | убрана карточка «Удалённые», из фильтра статуса убран «Удалённые», организации и динамика без удалённых | ✅ |
| 6 | Визуально понятное разграничение активных и деактивированных | зелёный / оранжевый: точки-маркеры, доли, полоса «активные / деактивированные» | ✅ |
| 7 | Всего профилей = активные + деактивированные | расчёт; профили в прочих статусах не учитываются | ✅ |
| 8 | Активные — неудалённые со статусом «Активен» | расчёт | ✅ |
| 9 | Деактивированные — неудалённые со статусом «Деактивирован» | расчёт | ✅ |

## Решения по UX
- Одна карточка «Профили» вместо четырёх KPI: всего → активные → деактивированные, у статусов доля
  и общая полоса. Число пользователей — справа в шапке этой же карточки, второстепенно, с подсказкой
  (оставлено, потому что есть в обоих референсах).
- «Профили по типам» — таблица: Всего / Активные / Деактивированные; сверху полоса долей типов (как раньше).
  Строки «Итого» нет: она дублировала бы карточку «Профили» (в референсе — дубль).
- Фильтр «Статус профиля» подсвечивает выбранный статус в карточке и в таблице (контекст не теряется),
  организации и динамику — фильтрует.
- Сумма по типам = всего профилей (подсказка «сумма больше числа пользователей» больше не нужна).
