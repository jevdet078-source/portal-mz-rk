# Карта страниц

20 файлов `.dc.html` в `project/`: 17 страниц + 3 общих компонента.
Все страницы, кроме «Вход», «Кабинет врача» и «Профиль врача», собираются по схеме
`Header → контент → Footer → Assistant`. Кабинеты (бизнес и медработник) — `Header layout="app"` сверху,
под ним меню кабинета слева (`BusinessNav` / `DoctorNav`) и контент.

## Общие компоненты

| Файл | Размер | Что делает |
|---|---|---|
| `Header.dc.html` | 7.6 КБ | Герб + название МЗ, переключатель ролей (Гражданам / Бизнесу / Медперсоналу), язык ҚАЗ/РУС/ENG, кнопка «Войти». Проп `variant="account"` прячет роли и логин, показывает «На главную». Роль хранится в `localStorage['mp-role']` и рассылается событием `mp-role-change`. В кабинете бизнеса (`variant="account"` + `org`) чип организации — кнопка с меню: организация, БИН и переключатель роли **Заявитель / Администратор** (`localStorage['mp-biz-role']`, событие `mp-biz-role-change`). Активная роль всегда видна плашкой в чипе. |
| `Footer.dc.html` | 5.6 КБ | Подвал, 1440×360. |
| `Assistant.dc.html` | 11.9 КБ | Плавающая кнопка AI-помощника + чат. Подключается почти везде с `hint-size="1px,1px"`. |
| `BusinessNav.dc.html` | — | Меню кабинета бизнеса (272 / 80 px, сворачивается). Пропсы `active`, `collapsed="1"`. Пункты открываются по онбордингу из `localStorage['mp-biz-step']`. В роли администратора к ним добавляется группа «Администрирование» → «Пользователи», «Организации», «Рабочий календарь». |
| `DoctorNav.dc.html` | — | Меню кабинета медработника (252 px) под общей шапкой — по образцу `BusinessNav`: подпись «Кабинет врача», 1) Профиль врача, 2) Электронный паспорт здоровья — порядок по замечанию аналитика. Проп `active` = `profile` / `epz`. Внизу — «Выйти из системы» (сбрасывает `mp-profile`, `mp-iin`); врач с фото — в шапке. Обёртка `dn-host`: `sticky; top:73px; height:calc(100vh - 73px); z-index:41`. Клик по активному пункту шлёт `mp-doc-nav-home`; если страница объявила `window.mpDocGuard()` и он вернул ФИО пациента (открыт ЭПЗ с сессией доступа), уход спрашивает подтверждение — в том числе по ссылкам шапки (событие `mp-doc-leave-request`). |
| `CitizenNav.dc.html` | — | Меню личного кабинета гражданина: карточка «кто вошёл» (фото `lk-avatar`, ФИО, ИИН, ОСМС) + разделы + «Выйти» (сбрасывает `mp-profile`, `mp-iin`). Проп `active` = `overview` / `lmk` / `notif`. Разделы по замечанию аналитика: Обзор, Личная медицинская карта, Уведомления. Разделы «Личного кабинета» — ссылки `Личный кабинет.dc.html#epz`: внутри страницы меняется hash, с других страниц — обычный переход. Подключается в обёртке `cn-host` (sticky); ≤1024px карточка сжимается в строку, разделы — горизонтальная лента с автопрокруткой к активному пункту. |

`Header` в варианте `account` принимает также `org` и `bin` — плашка организации в кабинете бизнеса,
и `layout="app"` — шапка на всю ширину (слева 16px, справа 32px) для страниц кабинета с сайдбаром.
В варианте `account` вместе с `layout="app"` появляется колокольчик уведомлений: бейдж с числом непрочитанных, выпадающий
список последних трёх и «Посмотреть все» → `Уведомления.dc.html` (Figma 6406:104361).
Кабинет медработника: `cabinet="medical"` + `user` и `place` — на месте организации чип врача (фото из
`localStorage['mp-doc-photo']` или значок пользователя, клик — в «Профиль врача»), в колокольчике — уведомления врача
(прочитанные — `localStorage['mp-doc-notif-read']`). Шапка на всех ширинах 73px; ≤1024 — «На главную» иконкой,
≤860 — чипы организации / врача без текста, ≤640 — без названия министерства, уведомления на всю ширину.

`BusinessNav` подключается с `style="height:100%;"`: рантайм переносит высоту на обёртку `div.sc-host`,
без этого меню не растягивается на всю высоту колонки.
