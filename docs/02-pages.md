# Карта страниц

20 файлов `.dc.html` в `project/`: 17 страниц + 3 общих компонента.
Все страницы, кроме «Вход», «Кабинет врача» и «Профиль врача», собираются по схеме
`Header → контент → Footer → Assistant`. Кабинеты (бизнес и медработник) — `Header layout="app"` сверху,
под ним меню кабинета слева (`BusinessNav` / `DoctorNav`) и контент.

## Общие компоненты

| `Header.dc.html` | 7.6 КБ | Герб + название МЗ, переключатель ролей (Гражданам / Бизнесу / Медперсоналу), язык ҚАЗ/РУС/ENG, кнопка «Войти». Клик по активному пункту шлёт `mp-doc-nav-home`; если страница объявила `window.mpDocGuard()` и он вернул ФИО пациента (открыт ЭПЗ с сессией доступа), уход спрашивает подтверждение — в том числе по ссылкам шапки (событие `mp-doc-leave-request`). |
| `CitizenNav.dc.html` | — | Меню личного кабинета гражданина: карточка «кто вошёл» (фото `lk-avatar`, ФИО, ИИН, ОСМС) + разделы + «Выйти» (сбрасывает `mp-profile`, `mp-iin`). Проп `active` = `overview` / `lmk` / `epz-view` / `epz-access` / `services` / `notif`. Фото профиля: клик по фото / камере → окно «Изменение фото профиля» (предпросмотр с перемещением и масштабом, «Выберите файл» / перетаскивание, JPG, JPEG, PNG до 5 МБ, ошибки формата, размера, файла и загрузки), хранение `mp-avatar` (JPEG 400×400), событие `mp-avatar-change`, сценарий `mp-avatar-scn` (sessionStorage: `ok` / `fail`). Разделы: Обзор, Личная медицинская карта, **Электронный паспорт здоровья (ЭПЗ)**, Услуги — раскрывающаяся группа «Просмотр ЭПЗ» / «Управление доступами к ЭПЗ» (раскрыта, когда открыт подраздел; на ≤1024px подразделы идут в ленте отдельными пунктами), Уведомления. Разделы «Личного кабинета» — ссылки `Личный кабинет.dc.html#epz`: внутри страницы меняется hash, с других страниц — обычный переход. Подключается в обёртке `cn-host` (sticky); ≤1024px карточка сжимается в строку, разделы — горизонтальная лента с автопрокруткой к активному пункту. |

`Header` в варианте `account` принимает также `org` и `bin` — плашка организации в кабинете бизнеса,
и `layout="app"` — шапка на всю ширину (слева 16px, справа 32px) для страниц кабинета с сайдбаром.
В варианте `account` вместе с `layout="app"` появляется колокольчик уведомлений: бейдж с числом непрочитанных, выпадающий
список последних трёх и «Посмотреть все» → `Уведомления.dc.html` (Figma 6406:104361).
Кабинет медработника: `cabinet="medical"` + `user` и `place` — на месте организации чип врача (фото из
`localStorage['mp-doc-photo']` или значок пользователя, клик — в «Профиль врача»), в колокольчике — уведомления врача
(прочитанные — `localStorage['mp-doc-notif-read']`). Шапка на всех ширинах 73px; ≤1024 — «На главную» иконкой,
≤860 — чипы организации / врача без текста, ≤640 — без названия министерства, уведомления на всю ширину.

`BusinessNav` подключается с `style="height:100%;"`: рантайм переносит высоту на обёртку `div.sc-host`,
без этого меню не растягивается на всю высоту колонки.
