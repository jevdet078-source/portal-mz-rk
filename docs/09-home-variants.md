# Новая главная: варианты A–E, палитры бренда, заставки

Задача (19.10.2026): руководство и вице-министр не приняли текущую главную — «похожа на систему
с дашбордами», пустые поля по бокам на больших мониторах, цвет «тёмный и банальный».
Нужны несколько вариантов главной (UX и UI), выбор брендового цвета и серьёзная заставка при входе.
Текущая главная (`Портал Минздрава - Главная.dc.html`) **не тронута** — оставлена для сравнения.

Начинать показ с витрины **`Главная - варианты.dc.html`**: варианты, палитры с проверкой контраста, заставки.

## Варианты

| Файл | Идея | Первый экран |
|---|---|---|
| `Главная A - Ясный` | Сервис прежде всего | Заголовок по роли + поиск с подсказками; справа — 6 популярных услуг. Ниже — разделы карточками со ссылками (без скрытых мега-панелей), плашка 103/112 для граждан |
| `Главная B - Стекло` | Сияние и глубина, «вау» | Знакомая структура (плитки разделов + поиск + выпадающая панель раздела) на глубоком цвете бренда с CSS-«сиянием» и стеклом. Популярные услуги «бенто» |
| `Главная C - Жизненные ситуации` | От задачи человека | «Кто вы?» — три крупные карточки ролей (вкладки ролей в шапке скрыты) + поиск. Ситуации: «Заболел», «Нужна справка», «Открываю аптеку»… по 2–3 действия |
| `Главная D - Официальный` | Визитная карточка министерства | Служебная строка с 103/112/1414, орнамент, золотая линия, витрина «Новое на портале»; справочник услуг тремя колонками, «Портал в цифрах» |
| `Главная E - AI-помощник` | AI в центре | «Здравствуйте! Чем помочь?» — ответ с кнопкой к услуге прямо на первом экране; разделы и популярные услуги под полем |

Состав контента во всех вариантах тот же, что на текущей главной: роли, госуслуги (у «Медперсоналу» — нет),
разделы и ссылки, «Часто ищут», «Новое на портале», «Полезные ссылки» (бизнес), трёхуровневый FAQ,
новости с рубриками, AI-помощник. Добавлено только то, что уже есть в портале: популярные госуслуги
с официальными названиями и кодами eGov.kz (из `Государственные услуги.dc.html`), справочники.

## Общие компоненты (только для новых вариантов)

| Файл | Что делает |
|---|---|
| `HomeData` | Невизуальный: `window.mpHome` + событие `mp-home-ready`. Контент по ролям, 10 палитр, `applyTheme`, орнамент (`--hm-orn`), доступность, `search()`, `botReply()`. В helmet — общие стили `.hm-*` |
| `PortalHeader` | Шапка: `look` = `light` / `glass` (прозрачная над баннером, стекло при прокрутке) / `official` (служебная строка); `roles="0"` прячет вкладки ролей. Кнопка «Доступность» |
| `SearchBox` | Поиск с подсказками по услугам и разделам при вводе, ↑/↓/Enter/Esc, «Спросить AI-помощника»; чипсы «Часто ищут». `look`, `size`, `chips`, `center`, `hotkey` («/») |
| `AiPanel` | Одна AI-панель справа вместо двух чатов текущей главной; открывается кнопкой или событием `mp-ai-open { q }` |
| `HomeFaq` | FAQ; аудитория следует за ролью в шапке |
| `HomeNews` | Новости: `layout` = `grid` / `editorial`; у новостей без картинки — обложка в цвете бренда |
| `PortalFooter` | Подвал в цвете бренда с орнаментом и номерами 103 / 112 |
| `Splash` | Заставка: `emblem` / `ornament` / `pulse` / `curtain` / `off` (`localStorage['mp-splash']`), раз за сеанс, ≈ 2 с, пропуск кликом/Esc; `auto="0"` — только по событию `mp-splash-replay` |
| `ThemeKit` | Кнопка «Варианты дизайна» слева внизу (только прототип): вариант, палитра, заставка |

Новые ключи хранилища: `mp-theme` (id палитры), `mp-splash` (стиль заставки), `mp-a11y` (`{ size, contrast }`),
`sessionStorage['mp-splash-seen']`, `sessionStorage['mp-tk-open']`.
Ссылки для показа: `?role=business`, `?theme=teal`, `?splash=off` / `?splash=ornament`.

## Палитры бренда

Новые хексы — по прямому решению владельца продукта («подобрать цвет для бренда»), это исключение из
правила «только палитра AlignUI». Нейтральные цвета остаются AlignUI. Шкала каждой палитры:
`b50 … b950` + акцент `bacc`. Правило: **600** — кнопки (белый текст ≥ 4,5:1), **700** — ссылки и текст на
светлых плашках, **50–200** — фоны, **900–950** — тёмные баннеры, акцент — точки, линии, свечение.

|---|---|---|---|---|
| `sky` ★ | Небесная лазурь — цвет флага | `#0B7AA6` | 4,8:1 | `#E3A92B` (золото) |
| `teal` | Бирюза | `#0B7F75` | 4,9:1 | `#F2A541` |
| `clinic` | Клинический синий | `#1F63D8` | 5,5:1 | `#16B3A3` |
| `ocean` | Глубокий океан | `#0E6E84` | 5,9:1 | `#E9B949` |
| `emerald` | Изумруд | `#0B7A4F` | 5,4:1 | `#E7B23A` |
| `sage` | Шалфей | `#3A7553` | 5,5:1 | `#C99A4B` |
| `sapphire` | Сапфир | `#2A47B8` | 7,8:1 | `#D9A93A` |
| `indigo` | Индиго — текущий | `#4D42E9` | 6,4:1 | `#35B9E9` |

| `graphite` | Графит и золото | `#2F3744` | 12,0:1 | `#C8962E` |

После выбора палитры её надо перенести в `design-system` через Claude Design (токены `primary-*`)
и заменить `--primary` в общих `Header` / `Footer` / страницах.

## Принципы

- Ширина: фоны от края до края, контент до 1760 px (`--wrap`), отступы `clamp()`; основа — ноутбук 1366–1536.
- Производительность: без 3D, видео и фото на первом экране; сияние и орнамент — CSS (маска из svg 1 КБ).
- Доступность: контраст AA, видимый фокус, клавиатура, `prefers-reduced-motion`, крупный текст и контраст.
