## Можно делать прямо сейчас

- [x] **Паспорт услуги: внутренние услуги** `price-ls`, `price-mi` (флаг `internal`, «Получить услугу», гейт).
- [ ] Паспорт `license-pharma` — нужны реальные условия услуги (срок, стоимость, НПА).
- [x] **Развести ссылки бизнеса на главной** — «Фармацевтика» и «Новое на портале» ведут в паспорта.
- [x] **Вход: параметр `return`.** Работает для профиля «Бизнес».
- [ ] **Вход: расшить тупики.** «Бизнес» ведёт в кабинет; «Госорган» пока тупик.
- [x] **Кабинет бизнеса** — главная с онбордингом, «Мои процессы», страница процесса (из Figma «Единого окна»).
- [x] **Кабинет бизнеса: Договора** — перечень, iframe НЦЭЛС, оферта ННЦРЗ.
- [x] **Кабинет бизнеса: Платежи** — iframe «Экспертиза».
- [x] **Кабинет бизнеса: Услуги** + паспорт и мастер регистрации цены ЛС / МИ (демо, часть заявителя).
- [x] **Заявление КНФ** — мастер из 5 шагов + этапы проверки ННЦРЗ (Figma 12090:234953, часть заявителя).
- [x] **Раздел уведомлений** — колокольчик в шапке кабинета + Центр уведомлений (Figma 6203:227749).
- [ ] Паспорт услуги КНФ на портале («Бизнесу → Фармацевтика») — нужны условия услуги (стоимость, порядок оплаты 20/80, основания для отказа). Сейчас КНФ подаётся из кабинета: Услуги → «Создать».
- [ ] КНФ: остальные этапы рассмотрения (договор и платёжное поручение 80%, заключение экспертизы) — в Figma есть, в прототипе показаны ожидание, счёт 20% и автоматическое включение.
- [ ] Регистрация цены: остальные пути (внесение изменений; отечественный / контрактный тип цены; МИ «производимого в РК» и «in vitro»).
- [x] Связать портальный `Паспорт услуги.dc.html` и главную («Бизнесу → Фармацевтика») с кабинетом и реестром Услуг.
- [ ] «Выйти» в `Личный кабинет` и `Кабинет врача` не сбрасывает `mp-profile` — поправить, прежде чем показывать «Кабинет» в шапке для всех профилей.
- [x] Гейт «Получить услугу»: не вошёл → вход с возвратом; онбординг не пройден → окно с шагами и возвратом к услуге.
- [ ] Привести тени прототипов к токенам DS (`--sh-*` → `--shadow-*`) — сейчас расходятся.

## Недостающие компоненты

Разбор по каждому — что нашлось в Figma-библиотеке AlignUI 1.0, под каким именем
и с какими вариантами — в `docs/07-figma-pickup.md`.

Перенесено из Figma в `project/` — подробности в `docs/08-components.md`:

- [x] `FileUpload.dc.html` — зона загрузки, карточки файлов, иконки форматов
- [x] `DatePicker.dc.html` — одиночная дата и диапазон с 8 пресетами, русская локаль
- [x] `Toast.dc.html` — 5 статусов × 4 стиля × 3 размера, принимает пропсы
- [x] `Table.dc.html` — реестр заявок: сортировка, выделение, все типы ячеек
- [x] `Dropdown.dc.html` — меню действий и комбобокс с поиском
- [x] `Combobox` — собран внутри `Dropdown.dc.html`

Рисуем сами — в библиотеке 1.0 нет:

- [ ] `Stepper` / `Wizard` — есть только `Stepper Dot`, мастер собираем из точек
- [ ] `Timeline` / `StatusHistory`
- [ ] `Drawer` / `SidePanel` — либо точечно забрать из библиотеки 2.0

Вынести из существующих страниц, черновики уже свёрстаны инлайном:

- [ ] `SegmentedControl` — главная, `Каталог услуг.dc.html`

селектор размера страницы для `Pagination`.
