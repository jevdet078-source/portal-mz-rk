# Папка для входящих материалов

Сюда кладём то, что приходит извне, до разбора:

- архивы дизайн-системы из Claude Design (распакованные или как `.zip`);
- выгрузки экранов и флоу из Figma;
- документы-требования, регламенты, НПА.

После разбора содержимое уходит по своим местам
(`project/_ds/`, `project/*.dc.html`, `docs/`), а отсюда удаляется.
