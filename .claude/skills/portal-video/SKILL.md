# Видео для аналитиков

Видео заменяет созвон: по нему аналитик и разработчики видят поведение экранов, ветки сценария
и тексты ошибок. Записываются **только сценарии текущей задачи**: при доработке — только правки,
а не весь раздел.

## Команда

```bash
npm run record -- <сценарий> --voice --tts=edge --no-subs
```

- Сервер прототипов (`node tools/serve.mjs` или `preview_start`) должен быть запущен. Порт не 5173 —
  добавить `--port=<порт>`.
- Голос Remy (`fr-FR-RemyMultilingualNeural`) через `uvx edge-tts`, нужен интернет. Сервис
  иногда отвечает «No audio was received», рекордер сам повторяет фразу до 12 раз.
- Результат — `exports/video/<N>. <Название>.mp4` (папка в `.gitignore`). Номер — следующий после
  последнего в `exports/video`.
- Запуск долгий, поэтому запускать в фоне (`run_in_background`) и дождаться уведомления.

## Сценарий `tools/record/<имя>.mjs`

Образец — `tools/record/my-family-unified.mjs`. Шапка файла:
```js
export const title = '<Название>';
export const fileName = '<N>. <Название>';
export const start = '<Стартовая страница>.dc.html';
export const voice = true;
export const viewport = { width: 1536, height: 864 }; // ноутбук 15–16″
```
API контекста (`export default async function record(ctx)`): `title(надзаголовок, заголовок,
подзаголовок, мс, озвучка)` — заставка (в образце переименована в `card`); `at(x, y)` — курсор в точку;
`section(имя, async () => …)` — блок сценария; `point(текст, селектор)` — подвести курсор;
`click(текст, селектор)`; `say(заголовок, текст, мс, озвучка)` — субтитр и фраза;
`waitText(текст, мс)`; `open(страница)`; `sleep(мс)`.

Правила:
- **Четвёртый аргумент `say()` — то, что читает голос.** Аббревиатуры и числа писать словами
  («Э-Пэ-Зэ», «двадцать процентов»). Английские термины — латиницей (`dashboard`), иначе Remy
  читает кириллицу по-русски с неверным ударением. Экранный текст остаётся русским.
- Панель «Прототип» в кадре скрыть (`.pp{display:none}`), состояния сервиса переключать
  за кадром через `sessionStorage`. Перед записью сбросить демо-данные.
- Ховеры показывать настоящей мышью (`page.mouse.move`). Темп спокойный, паузы по длине фразы.
- Заставки разделов остаются, субтитров нет: голос их заменяет.
- Порядок: заставка задачи → каждый пункт постановки отдельным `section` → итоговое состояние.
  Длина — столько, сколько нужно для пунктов, без воды (обычно 2–5 минут).

## После записи

1. Посмотреть несколько кадров (ffmpeg, кадр каждые 20–30 с) и проверить, что сценарий не
   сломался на полпути, ничего не перекрыто, курсор на месте.
2. Если при записи нашлась ошибка в прототипе — исправить, перезаписать и сказать об этом
   пользователю прямо: что было и что исправлено.
3. Сценарий закоммитить (`tools/record/<имя>.mjs`), само видео в git не идёт.
4. Пользователю — путь к файлу. В отчёте аналитику — название ролика.
