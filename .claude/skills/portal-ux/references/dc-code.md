# Код `.dc.html` — как правильно и как не сломать

Полное описание формата — `docs/04-dc-format.md` (прочитать при первой правке в сессии).
Здесь собрано то, на чём уже спотыкались.

## Структура

- Правим только `project/*.dc.html`. В `design-system/` руками ничего не меняем: это выгрузка из
  Claude Design.
- Структура плоская: никаких подпапок в `project/`, ссылки относительные, имена файлов русские,
  как есть (`href="Мои заявки.dc.html"`).
- Шапка, подвал, навигация кабинетов, помощник подключаются только через
  `<dc-import name="…">`. Вёрстку не копировать. Правка общего компонента — в его файле,
  и проверить все страницы, где он подключён.
- Файл разросся больше ~150 КБ или кусок повторяется в двух местах — вынести в компонент
  `.dc.html` (так из `Кабинета врача` вынесли `EpzView`).
- Пропсы приходят строками, флаги — `"0"` / `"1"`.

## Рантайм

- `renderVals()` возвращает плоский объект. В разметке `{{ ключ }}`, циклы — `<sc-for>`, условия —
  `<sc-if>`. Пустые блоки не рендерить через `sc-if` (иначе лишние отступы, дефект Б6).
- `setState` меняет `this.state` синхронно. `componentDidUpdate` получает только `prevProps`,
  прошлое состояние при необходимости хранить самим.
- Стили: статичные — классами в `<style>` внутри `helmet` (`:hover`, `:focus-visible`,
  `@media`). Вычисляемые — строкой стиля из `renderVals()`. Ховер на инлайн-стиле не
  сделать, поэтому кликабельное оформлять классом.
- Цвета только из `:root`-переменных файла (они совпадают с токенами AlignUI, таблица —
  `docs/03-design-system.md`). Новых хексов нет.
- Иконки `ri-*-line` / `ri-*-fill`, размеры 16 / 18 / 20 / 24. Имя из Figma сверить с RemixIcon
  4.5 (например, `select-box-circle-fill` → `ri-checkbox-circle-fill`).
- Состояние между страницами — `localStorage` / `sessionStorage` с префиксом `mp-`. Новый ключ
  записать в таблицу `docs/04-dc-format.md`. Синхронизация — событием `window`
  (`mp-<что>-change`).
- Асинхронные данные (`EdData` и пр.) приходят событием `*-ready`. До него показывать скелет,
  а не пустоту.

## Правка файлов скриптом

- Bash съедает обратные слэши в `node -e` и heredoc, а обратные кавычки выполняет как команды.
  Регулярки, `\u`-последовательности, markdown — только через Write во временный `.mjs` /
  `.cjs` в scratchpad, затем запуск файла. После правки проверить результат через Grep.
- Точечные правки — инструментом Edit. Большие файлы перед правкой читать нужным диапазоном.
- `package.json` проекта — `"type": "module"`: CommonJS-скрипты называть `.cjs`.

## Сервер и браузер

- `preview_start({ name: "prototypes" })` (`.claude/launch.json`, `autoPort`). Порт занят другой
  сессией — сервер поднимется на свободном, взять адрес из результата.
- `.dc.html` через `file://` не открывается, только через сервер. Выгрузка `exports/portal-mz-rk`
  открывается двойным кликом.
- Если видна старая версия — перезагрузить вкладку (`location.reload()`).
- Проверять короткими синхронными `javascript_exec`. Если панель браузера скрыта, анимации
  и `requestAnimationFrame` стоят; скриншот делать отдельным вызовом.
