# Главная страница портала

Главная — визитная карточка Министерства здравоохранения. Её смотрят вице-министр
и руководство. Требования, которые они уже высказали:

- **Это портал, а не система с дашбордами** (19.10). Витрина услуг, жизненные ситуации, поиск
  и помощник, а не KPI-плитки.
- **На всю ширину экрана.** Пустые бока на 27″ им не нравятся. Начинаем с ноутбука (1366–1536),
  на мониторах контент растягивается и адаптируется.
- **Строго, статусно, ничего лишнего.** Никаких текстов-пояснений: «из-за текста теряется суть
  портала».
- **Баннеры-карусели с услугами на первом экране** (22.10, по образцу банков): примерно половина
  ширины, автосмена каждые 5–10 с, пауза при наведении, стрелки, полоска-таймер, свайп на
  планшете. Слева — AI-помощник и поиск.
- **Фото врачей на первом экране** (09.11, просьба вице-министра). Цельным фоном, как на стенде
  `portal.isapp`, но без наложения текста на людей: заголовок над головами, поле поиска под
  людьми. Когда поверх появляются результаты, люди приглушаются.
- **Фото в «Здоровье на каждом этапе жизни»** — живые, люди казахской или центральноазиатской
  внешности (не явно восточноазиатской), качественные, лицензированные, деликатные. «Мягкое 3D»
  руководство считает мультяшным.
- **Цвет бренда.** Есть палитры с градиентами и без. Градиенты только пастельные и светлые
  (голубой, лазурь, бирюза), не тёмные переливы. Выбор палитр — `ThemeKit`.

## Варианты

- `Главная J - Итоговый` — актуальная, по образцу тестового стенда с исправленными ошибками.
  Новые блоки главной (опросник `HealthRoute`, `LifePath`, разделы) по умолчанию идут сюда.
- A–I — варианты для показа. Новый вариант = новый файл со следующей буквой, остальные не
  трогать. Пользователь сам говорит, на каких вариантах повторить новый блок (часто это
  «последние два-три»: G, H, I, J).
- Новый пункт шапки: на 1366–1440 места нет (Б5 в `defects.md`). Решение — компактный пункт
  с панелью, как «Инструкции», а не шестой пункт в ряд.

## Как сделать вариант лучше референса

Если пользователь даёт полную свободу («сделай свой лучший вариант»), начать с ресерча.
Посмотреть 3–5 эталонов: gov.uk, NHS, Госуслуги, eGov.kz, лучшие банки РК. Сформулировать одну
идею варианта одной строкой («жизненные ситуации вместо каталога», «помощник в центре»).
Держать её через всю страницу. Один сильный приём лучше пяти средних.

## Проверка главной

Помимо общего протокола:
- первый экран на 1366×768 и 1536×864: всё главное видно без прокрутки, шапка в одну строку;
- карусель: автосмена, пауза при наведении и фокусе, стрелки с клавиатуры, нет прыжка высоты
  между слайдами;
- выпадающий список поиска поверх всех блоков ниже (В4);
- на 2560 нет пустых боков и растянутых строк текста длиннее ~80 знаков.
