# Паттерны проекта — где уже лежит готовое решение

Прежде чем строить элемент, открыть образец и повторить его. Полный каталог страниц —
`docs/02-pages.md`, компоненты — `docs/08-components.md`, их API — `docs/03a-component-api.md`,
ключи `localStorage` — `docs/04-dc-format.md`. Новую страницу или компонент вписать в эти
документы и в `GROUPS` файла `tools/export.mjs`.

## Каркас страниц

| Что строим | Образец | Заметки |
|---|---|---|
| Публичная страница раздела | `Клинические протоколы`, `Государственные услуги`, `Инструкции` | Шапка `PortalHeader` (на главных G–J и их разделах) или `Header`, подвал `PortalFooter` / `Footer`. На мониторах — на всю ширину |
| Главная | `Главная J - Итоговый` (актуальная), A–I — варианты | `references/home.md`. Общие куски: `HomeData` (данные, `data-tip`), `HomeBanners`, `HomeAssist`, `AiPanel`, `SearchBox`, `HomeFaq`, `HomeNews`, `HealthRoute`, `LifePath`, `ThemeKit` |
| Кабинет бизнеса | `Кабинет бизнеса`, `Услуги`, `Мои заявки` | `Header layout="app"` + `BusinessNav`. Роль заявитель / администратор — переключатель в шапке (`mp-biz-role`) |
| Кабинет гражданина | `Личный кабинет`, `Моя семья`, `Мои заявки гражданина` | `CitizenNav` |
| Кабинет врача | `Кабинет врача`, `Профиль врача` | `Header cabinet="medical"`, `DoctorNav`. ЭПЗ — компонент `EpzView` (`mode="doctor"`) |
| АРМ ведомства | `АРМ ННЦРЗ`, `АРМ ФК`, `АРМ НЦЭЛС` | `ArmHeader` («Работать от имени»), `ArmNav`, `ArmNotifications` |
| Админ-панель | `Пользователи`, `Организации`, `Дашборд`, `Рабочий календарь` | Реестры с вкладками, фильтрами и сортировкой в `sessionStorage` |
| Отчётность руководителя | `Администрирование отчётности`, `Журнал отчётных форм`, `Отчётные формы` | `OrgReportsNav`, `OrgRepData`; «Показ прототипа» в строке крошек |

## Типовые блоки

| Блок | Образец | Заметки |
|---|---|---|
| Паспорт услуги | `Паспорт услуги ЕД`, `Паспорт услуги АЛО`, `Паспорт услуги ЗОБ`, `Паспорт услуги КНФ`, `Паспорт услуги прикрепления` | **Один шаблон на все паспорта.** Новый паспорт — копия ближайшего с заменой данных |
| Мастер подачи (степпер) | `Заявка ЕД` (`?svc=alo`), `Прикрепление к поликлинике` | Шаги, черновик в `sessionStorage`, подписание `EdSign` |
| Карточка заявки | `Карточка заявки ЕД` (заявитель), `Карточка заявки ННЦРЗ` (эксперт) | Сводка сверху, документы, хронология — каждое в одном месте |
| Реестр с фильтрами | `Прочие услуги`, `Мои заявки`, `Мои заявки гражданина`, `АРМ ННЦРЗ` | Компактная строка фильтров, сортировка, пагинация, пустое состояние |
| Таблица | `Table.dc.html` (витрина AlignUI) | Плотность 64/48, ячейки со статус-бейджем, сортировка. Обводка плашки — `border` |
| Выпадающий список, комбобокс | `Dropdown.dc.html` | Поиск в самом поле. Не нативный `<select>` |
| Дата и период | `DatePicker.dc.html` | Русская локаль, неделя с понедельника, пресеты периодов |
| Загрузка файлов | `FileUpload.dc.html` | Зона, карточки файлов со статусами, цвета форматов |
| Уведомление | `Toast.dc.html` | 5 статусов × 4 стиля. Вместо окна «Успешно» |
| Подписание ЭЦП | `EcpPicker` (выбор ключа, тестовые учётки `mp-users`), `EdSign` (пароль → проверка) | Пароль тестовых ключей — 1 |
| Просмотр документа / PDF | `EdDocView` | Протоколы, заключения, счета |
| Уведомления | `Уведомления` (бизнес), `ArmNotifications` (АРМ), колокольчик в `Header` | Прочитанные — в `localStorage`. В реестре текст уведомления — второй строкой записи в подложке (непрочитанное — сиреневая с полосой, прочитанное — светлая с обводкой; не узким столбцом), поиск по тексту и номеру с подсветкой (19.11, 23.11) |
| Инструкции и видео | `HelpCenter` (`mode="panel" / "page" / "viewer"`) | Пункт «Инструкции» компактной шапки |
| Подсказка | `data-tip="…"` (механизм в `HomeData`; в АРМ — `.tip` / ⓘ у заголовка формы) | Единственный способ показать пояснение |
| AI-помощник | `Assistant` (плавающий), `HomeAssist`, `AiPanel` | Кнопку над нижней панелью поднимает `--mp-fab-bottom` |

## Данные и состояния прототипа

| Что | Образец |
|---|---|
| «Бэкенд» услуги: хранилище, статусы, сроки в рабочих днях, нумерация, демо-набор | `EdData` (`window.mpEd`, событие `mp-ed-ready`). ЕД и АЛО — один движок, отличия в `SVCS[svc]` |
| Данные раздела гражданина | `AttachData` (`mpAttach`), `FamilyData` (`mpFamily`), `LifeStagesData` |
| Данные отчётности | `OrgRepData` (`mpOrgRep`) |
| Переключение ответа сервиса | панель «Прототип» (класс `.pp`) с ключом `mp-<раздел>-scn` в `sessionStorage`: `ok / empty / partial / slow / down / error …` |
| Сброс демо-данных | кнопка «Сбросить данные» в панели «Прототип» |
| Сжатые сроки для показа | `mp-ed-fast` (минуты вместо рабочих дней) |

## Паттерны решений, уже согласованные с аналитиками

- Госуслуги — **страницами**, не модальными окнами (13.10).
- Услуги кабинета бизнеса: в сайдбаре подразделы «Фармацевтика» и «Лицензирование
  и аккредитация», услуги показываются справа (29.10).
- Выбор услуги ЛС / МИ в окне — сегментированный переключатель (28.10).
- Оплата госпошлины: выбор вида пошлины → «Перейти к оплате» (ПШЭП / Halyk) → статусы оплаты.
  Без ручной загрузки чека и без самодельного окна банка (20–21.10).
- Замечания эксперта к полям (АЛО) исправляются прямо в полях, затем статус «Проверка доработки».
- Мониторинг руководителя — только информация, без ссылок в админку (13.11).
- Пункты, которым нет места в шапке, — компактный пункт с панелью, как «Инструкции» (08.11).
