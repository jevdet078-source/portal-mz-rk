# Шаблоны текстов для Telegram

Все тексты отдаются одним блоком ```text: мужской род, к аналитику на «вы», жирный `**…**`,
списки «•». Квадратные скобки — подставить. Пустые разделы удалить.

## 1. Отчёт по задаче (основной)

```text
Добрый день!

Готов UX/UI-дизайн [раздела «…» / доработки «…»] по вашей постановке[ от ДД.ММ]. [Ваш прототип использовал как ориентир: сделал проще и с меньшим числом кликов.]

**Что сделано**

**1. [Блок или экран]**
• [что сделано — простыми словами, с названиями из постановки]
• […]

**2. [Блок или экран]**
• […]

**Решения по UX сверх постановки:**
• [коротко, 1–3 пункта — только заметные]

**Где посмотреть:**
Распакуйте архив portal-mz-rk.zip и откройте «00 — Открыть прототип.html» (лучше в Chrome или Edge, интернет не нужен).
• [Роль] → [раздел] → [вкладка] → «[кнопка]»
• [демо-данные: заявка 0000126, ИИН …] · пароль ЭЦП — 1
• Состояния сервиса переключаются в панели «Прототип» слева внизу[, «Сбросить данные» возвращает исходные заявки]

**Вопросы:**
1. [вопрос] Сейчас сделал так: [вариант].
2. […]
```

## 2. Доработка по замечаниям

```text
Добрый день!

Внёс правки по вашим замечаниям к [разделу «…»] от ДД.ММ.

**Что исправлено:**
1. [замечание своими словами] — [как сейчас]
2. […]

**Где проверить:**
• [путь до каждого исправления, коротко]

[**Вопросы:** …]
```

## 3. Общий отчёт за период (несколько задач)

Если задач больше двух, лучше отдельный блок ```text на каждую задачу, чтобы их можно было
отправить по очереди. Перед ними одной строкой пояснить пользователю, в каком порядке их
отправлять. Если задач две, можно одним текстом, с жирными заголовками задач.

## 4. Как открыть архив (новому аналитику или коллегам)

```text
Отправляю актуальный прототип портала.

**Как открыть:**
1. Распакуйте архив portal-mz-rk.zip (правой кнопкой → «Извлечь всё»).
2. В папке portal-mz-rk откройте двойным кликом «00 — Открыть прототип.html».
3. Откроется список всех страниц, сверху — «Что нового». Кнопка «Открыть портал» ведёт на главную.

Лучше открывать в Chrome или Edge, интернет не нужен.
[Чтобы войти: «Войти» → выбрать ключ ЭЦП [роль] → пароль 1.]
```

## 5. Текст разработчикам (только как открыть и войти)

Без воды и без описания функций. Путь к файлу в архиве, вход под нужной ролью, где функция.

```text
Прототип [раздела] — в архиве portal-mz-rk.zip.

**Открыть сразу:** папка portal-mz-rk → файл «[Страница].dc.html» (двойной клик, Chrome или Edge).
**Войти как [роль]:** «Войти» → ключ «[ФИО / организация]» → пароль 1.
**Где функция:** [раздел] → [вкладка].
```

## 6. Ответ на вопросы аналитика

Когда пользователь вставляет ответы аналитика («1. + 2. только активные…»): внести изменения,
затем короткий текст:

```text
Добрый день! Учёл ваши ответы:
1. [вопрос коротко] — [что сделал]
2. […]
Прототип обновил, архив приложу.
```

## Чек-лист перед отправкой

- Мужской род во всех глаголах о себе, «вы» к аналитику.
- Нет слов «телефон», «смартфон», «мобильный».
- Каждый пункт постановки упомянут. Вопросы пронумерованы, у каждого — текущий вариант.
- Путь «где посмотреть» действительно ведёт к функции. Проверить, пройдя его самому
  в выгрузке.
