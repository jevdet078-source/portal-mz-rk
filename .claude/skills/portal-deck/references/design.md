# Дизайн слайдов — практики и композиции

## Принципы (лучшие практики деловых презентаций)

- **Заголовок-вывод.** Если в исходнике заголовок — вывод («Три услуги уже доступны»), он
  получает самый крупный кегль. Если просто тема, то главный акцент слайда — опорный блок,
  а не тема. Новых заголовков не сочинять (правило 1 SKILL.md).
- **Один слайд — одна мысль.** Отвечает на вопрос «что должен вынести министр». Всё, что не
  работает на эту мысль, тише.
- **Тест 5 секунд.** Показать PNG себе на 5 секунд: что запомнилось? Если не главное — усилить
  контраст иерархии.
- **Чтение по Z.** Левый верх — заголовок и герб, центр — главный акцент, правый низ — итог
  или ключевая цифра.
- **Контраст.** Текст ≥ 4.5:1 к фону. На проекторе светлые полутона теряются: вторичный текст
  не светлее `--n500` на белом.
- **Числа.** `font-variant-numeric: tabular-nums`, крупная цифра + короткая подпись. Без
  десятичных хвостов, если их нет в исходнике.
- **Длина строки** до ~60 знаков; `text-wrap: balance` для заголовков и коротких абзацев.
- **Сетка 1920×1080:** поля 72 px слева и справа, 60 px сверху; колонки по 12-колоночной сетке,
  промежуток 24 px; скругления 16–28 px, одинаковые у одного уровня блоков.

## Палитра (из главной J, `assets/slide.css`)

| Токен | Цвет | Роль |
|---|---|---|
| `--navy` | `#0B3A50` | заголовки, тёмный фон |
| `--navy-deep` | `#072B3D` | тёмный фон, глубина |
| `--blue` | `#086286` | акцент, подзаголовки-эйлбраузы, цифры |
| `--blue-2` | `#0B7AA6` | градиент акцента |
| `--sky` | `#1AA3CF` | свечение, линии, акцент на тёмном |
| `--ice` / `--ice-2` | `#EEF8FC` / `#D6EEF7` | подложки иконок и блоков |
| `--n900` / `--n600` / `--n500` | | основной, вторичный, третичный текст |
| `--n200` | `#E2E4E9` | обводки |

Соотношение примерно 60 / 30 / 10: фон, нейтральные блоки, акцент. Тёмный вариант — навигация
`--navy-deep → --navy` с мягким свечением `--sky` (как в варианте C).

## Композиции (проверенные на слайде для министра)

| Имя | Идея | Когда брать |
|---|---|---|
| **Архитектура** | ярусы сверху вниз: аудитории → портал → АРМ, преимущества колонкой справа | печать, раздатка, самый сдержанный |
| **Продукт** | слева живой скриншот главной в рамке браузера, справа аудитории и АРМ, внизу полоса преимуществ | нужно показать, что портал уже существует (понравился аналитику, сделан в PPTX) |
| **Поток** | тёмный, слева направо: аудитории → белое ядро «Портал МЗ РК» → ведомства, линии-связи | показ на экране, эффектно |
| **Платформа** | портал — единый контейнер, АРМ встроены снизу, аудитории подключены линиями сверху | показать, что ведомства работают внутри портала |
| **Хаб** | портал в центре круга четырёх аудиторий, АРМ и преимущества по сторонам | идея «портал в центре» (понравился аналитику, сделан в PPTX) |
| **Шкала** | этапы или даты на горизонтальной оси, статус каждого этапа | сроки запуска, дорожная карта |
| **Цифра** | одна крупная цифра + 2–3 пояснения | ключевой результат |

Новый вариант по просьбе «сделай ещё лучше» — не усложнение, а более сильная идея: крупнее
шрифт, меньше рамок, один акцент, смысл через структуру.

## AI-слоп в слайдах — не делать

- сетка из 6–9 одинаковых карточек «иконка в кружке + заголовок + описание»;
- градиентные кляксы, glassmorphism и неоновые свечения ради эффекта;
- 3D-сток, абстрактные «цифровые» картинки, люди со стоков не нашей внешности;
- эмодзи, иконки разных наборов, иконка к каждому слову;
- «карточка в карточке», тени на всём, пять уровней серого;
- придуманные метрики, проценты, «+300 % эффективности»;
- слайд «Спасибо за внимание», «Вопросы?», если его не было в исходнике.

## Тексты на слайдах

Без переносов слов по слогам. Неразрывный пробел перед «—» и после коротких предлогов («в», «и»,
«к»), между числом и единицей («20&nbsp;филиалов»). Кавычки «ёлочки». Регистр предложения,
UPPERCASE — только в эйлбраузах с `letter-spacing: .05em`.
