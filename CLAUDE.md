# Портал Министерства здравоохранения РК — контекст проекта

## Что это

Единый портал МЗ РК. Дизайн сделан в **Claude Design**, выгружен как handoff-бандл
и дальше дорабатывается здесь, в Claude Code: и UX/UI, и реализация.

Три роли на портале: **Гражданам**, **Бизнесу**, **Медперсоналу**, плюс личные кабинеты
(физлицо, медработник) и справочно-информационные разделы.

## Структура репозитория

## Как смотреть прототипы

```bash
node tools/serve.mjs
```
→ `http://localhost:5173` — индекс всех страниц.

`.dc.html` **нельзя открывать через file://** — они подтягивают соседние компоненты
через `fetch()`. Только через локальный сервер.

Самодостаточные копии в `exports/standalone-html/` открываются двойным кликом,
но это снапшот — править их бессмысленно.

## Правила работы

1. **Правим только `project/*.dc.html`.** `design-system/` — выгрузка из Claude Design,
   руками её не редактируем: при следующей выгрузке правки затрёт. Недостающие
   компоненты проектируем как `.dc.html` в `project/`, а в саму DS они попадают
   уже через Claude Design.
2. **Не ломаем плоскую структуру `project/`.** Все ссылки между страницами относительные
   (`href="Каталог услуг.dc.html"`), `dc-import` ищет компоненты в той же папке.
   Подпапки внутри `project/` ломают импорт и обратную совместимость с Claude Design.
3. **Цвета — только из палитры AlignUI.** Прототипы объявляют свои `:root`-переменные,
   но значения совпадают с токенами DS один в один. Таблица соответствия —
   `docs/03-design-system.md`. Новых хексов не изобретаем.
4. **Иконки — только RemixIcon** (`<i class="ri-*-line">` / `ri-*-fill`). Никаких эмодзи.
   В пропах компонентов DS имя иконки передаётся **без префикса** `ri-`.
5. **Шрифт — Inter.** Регистр предложения в заголовках и кнопках, UPPERCASE только
   в подзаголовках-эйлбраузах (`letter-spacing:.04–.05em`).
6. **Язык интерфейса — русский.** В шапке есть переключатель ҚАЗ/РУС/ENG,
   но контент пока только русский.
7. Общие компоненты (`Header`, `Footer`, `Assistant`) правим в их собственных файлах —
   они подключаются во все страницы через `<dc-import name="Header">`.
8. **Крупные разделы режем на страницы.** `Кабинет врача.dc.html` уже 227 КБ в одном
   файле — так больше не делаем. Повторяющиеся куски выносим в отдельные
   `.dc.html`-компоненты и подключаем через `dc-import`.

## Формат .dc.html — коротко

Подробно: `docs/04-dc-format.md`.

- Разметка внутри `<x-dc>`, логика — в `<script type="text/x-dc" data-dc-script>`
  классом `class Component extends DCLogic`.
- Метод `renderVals()` возвращает объект; его ключи подставляются в разметку как `{{ key }}`.
- Управляющие теги: `<sc-if value="{{ flag }}">`, `<sc-for list="{{ arr }}" as="x">`.
- Стили — инлайновые, вычисляемые строки стилей формируются в `renderVals()`.
- Состояние между страницами передаётся через `localStorage` (`mp-role`, `mp-lang`,
  `mp-iin`, `mp-profile`) и событие `window` `mp-role-change`.
